CREDITS & ACKNOWLEDGMENTS

Honoring the technologies, libraries, and design foundations that power the TOMORROW'S YOU experience.

Game Concept & Architecture

Core Gameplay & Level Design

Deterministic temporal Echo recording engine, turn-based coordinate simulation, 10 handcrafted campaign chambers, and the 5-tier difficulty progression system.

Godot Engine 4.7.2

Game Engine & Runtime

Built with Godot Engine 4.7.2 Stable. Copyright © 2014-present Godot Engine contributors; Copyright © 2007-2014 Juan Linietsky, Ariel Manzur. Licensed under the permissive MIT License.

Procedural Audio Synthesis

Sound Effects & Ambient Music

Procedurally synthesized audio waveforms generated in-engine at runtime via Godot AudioStreamWAV APIs. Minimal asset footprint with zero external copyrighted audio tracks.

Visual Atmosphere & Shaders

Temporal Research Facility Engine

5-layer procedural environmental background, custom GLSL chromatic aberration and vignette shaders, reactive particle simulation, and dynamic theme palettes across all 5 difficulty tiers.

Android Mobile Integration

Platform Engineering

Portrait-locked architecture, cutout/notch safe-area margin handling, hardware back-button routing, high-touch-target 72×72px D-pad, and tactile haptic vibration engine.

Typography

Google Fonts & Typography

Space Grotesk by Florian Karsten; Inter by Rasmus Andersson; IBM Plex Mono by Bold Monday. All licensed under the SIL Open Font License (OFL 1.1).

Automated QA & Testing

Continuous Verification

129 automated unit, integration, and physical solvability tests passing in headless Godot, covering turn lookahead, daily hint allowances, and responsive mobile resolutions.

Web Performance & Hosting

Official Website Architecture

Modern static web presentation built with semantic HTML5, CSS custom properties, vanilla ES6 JavaScript, original SVG graphics, and deployed via Netlify global edge CDN.
