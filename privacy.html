Data Transparency

PRIVACY POLICY

Transparent data practices for the TOMORROW'S YOU mobile game and official web portal.

Pre-Launch Notice for Maintainers: This document reflects the actual static implementation of the website and the offline architecture of the Godot game. Before final publication on Google Play or public domains, please insert your official legal entity name and support email address in Section 7.

1. Overview and Core Philosophy

TOMORROW'S YOU is an indie single-player mobile game built with Godot Engine 4.7.2. Both the game software and this static documentation website are built with a strict privacy-first, offline-first philosophy.

We do not sell personal data, do not display commercial advertising, do not integrate behavioral tracking SDKs, and do not use hidden analytics.

2. The Mobile Game Application

The TOMORROW'S YOU Android game runs 100% locally on your mobile device:

  • Zero Telemetry: The game contains no third-party analytics SDKs (no Firebase Analytics, Google Analytics, Adjust, AppsFlyer, or Unity Ads).
  • Zero Advertising: There are no ad networks, interstitial ads, or tracking identifiers.
  • Local Save Storage: Level progress, star ratings, and daily hint allocations are saved locally in user://save.cfg on your physical device storage. This data never leaves your device.
  • Android Permissions: The game requests only the standard hardware vibration permission (android.permission.VIBRATE) for optional tactile haptic feedback during movement and Echo creation. It requires no location, camera, microphone, contacts, or storage permissions.

3. This Website and Web Server Logs

This website is a static HTML/CSS/JavaScript presentation hosted on Netlify:

  • No Tracking Cookies: This website sets zero advertising, session tracking, or marketing cookies.
  • No User Accounts or Forms: There are no account registration systems, comment forms, or newsletter subscriptions. We collect no names, emails, or passwords through this site.
  • Server Access Logs: Like all web hosting platforms, our static host (Netlify) automatically processes standard HTTP request logs (IP addresses, User-Agent strings, requested URLs, and timestamps) solely for security monitoring, DDoS mitigation, and content delivery network routing.

4. Third-Party Resources

This website loads web fonts from Google Fonts (Space Grotesk, Inter, and IBM Plex Mono) to ensure crisp typographic rendering. When your browser requests these font files, your IP address is received by Google's font delivery servers in accordance with Google's public privacy policies. If external fonts fail to load, the website automatically falls back to system fonts without any loss of functionality.

5. Children's Privacy

TOMORROW'S YOU does not knowingly collect or solicit any personally identifiable information from children under the age of 13. Because the game is strictly offline with no account creation or communication features, children can safely enjoy the puzzle adventure without data transmission.

6. Updates to This Policy

If our game features or web infrastructure evolve, this policy will be updated with a revised effective date. Any future changes will maintain our foundational commitment to user privacy and zero unwanted tracking.
